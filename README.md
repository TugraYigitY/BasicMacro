# BasicMacro

# Description
 A simple AutoHotkey macro that toggles auto-clicking with left click.
# Setup
 Download and install version v2.0 from "www.autohotkey.com".
 Download the "macro.ahk" file from this repository to a folder of your choice.
 Run the file by double-clicking it.
# Usage
 F6: Start-Stop the script.
 Left Click: Toogles the macro on-off.

# Requirements
 Windows operating system
 AutoHotkey v2.0
